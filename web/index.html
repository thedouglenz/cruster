Kubernetes TUI for the agent era

A paid k9s competitor built on three pillars: speed, ergonomics, and Claude Code compatibility. One CLI call to bundle a failing pod's manifest, events, and logs into a markdown your agent can read. Or a fast TUI when you'd rather drive it yourself.

Install View on GitHub
cargo install --git https://github.com/thedouglenz/cruster.git --bin cruster --locked

Three pillars

① Speed

Rust + ratatui. Cold start to first interactive frame in under 100 ms on a 100-pod cluster. Steady-state CPU under 5% on a 10k-pod cluster with the pods view open and scrolling. Memory under 200 MB resident.

② Ergonomics

Task-first, not resource-first. One keystroke jumps to a selected pod's owner chain, mounted configmaps and secrets, endpoints, recent events. Vim/emacs/normal keymap presets. Three named layouts. Search, relationships, history, workflows.

③ Agent-native

A first-class LLM-efficient CLI parallel to the TUI. Stable per-verb JSON schemas inlined into cruster help-json. cruster export bundles manifest + events + logs into one markdown for your agent. agentskills.io skills + a Claude Code plugin ship in the box.

Why your agent will prefer cruster

Diagnosing the same failing pod with kubectl vs cruster export. Smaller payload, fewer round-trips, one markdown your agent reads end-to-end.

kubectl

$ kubectl describe pod at-foo -n agent-platform
$ kubectl logs at-foo -n agent-platform
$ kubectl get events -n agent-platform \
    --field-selector involvedObject.name=at-foo
  • 4 calls
  • ~3.7 KB stdout
  • ~6.6 s wall
  • Agent stitches the output back together

cruster

$ cruster export pod/at-foo -n agent-platform
  • 1 call
  • One self-contained markdown bundle
  • Manifest + events + log tail in document order
  • Agent reads it linearly

Measured against the staged failing-pod scenario on a local k3d cluster. The cruster path was independently picked by an LLM agent given only cruster --help and the inline schemas in cruster help-json.

Agent compatibility

Three skills (cruster-investigate-pod, cruster-resource-bundle, cruster-recent-activity) plus a Claude Code plugin with matching slash commands. The skills follow the agentskills.io standard and drop into any compatible agent.

Agent Install path One-line install
Claude Code ~/.claude/skills/ ./install.sh --agent claude
Cursor ./.cursor/skills/ ./install.sh --agent cursor
Codex ~/.agentskills/ ./install.sh --agent generic
Gemini CLI ~/.agentskills/ ./install.sh --agent generic
Goose / OpenHands / Amp ~/.agentskills/ ./install.sh --agent generic

Cargo

cargo install --git https://github.com/thedouglenz/cruster.git \
  --bin cruster --locked

Any platform with a Rust toolchain.

Homebrew

brew tap thedouglenz/cruster
brew install cruster

macOS & Linux. Tap goes live once the first release ships.

Prebuilt binary

curl -L https://github.com/thedouglenz/cruster/releases/latest \
  | tar xz cruster

macOS arm64 / Intel and Linux x86_64.

From source

git clone https://github.com/thedouglenz/cruster.git
cd cruster/app && cargo build --release

Lands in app/target/release/cruster.
